# SWYNEX Interactive Dashboard

## Task 3 – Interactive Dashboard

This project presents an interactive sales dashboard created using Microsoft Power BI.

## Key Features
- Sales KPIs
- Sales analysis by City
- Sales analysis by Product
- Order count analysis
- Status-based analysis
- Interactive Product and Status filters

## Tool Used
- Microsoft Power BI

## Objective
To build an interactive dashboard that communicates important findings from the analyzed sales dataset clearly and effectively.
